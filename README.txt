PERSONAL PORTFOLIO - QUICK EDIT GUIDE

Files:
- index.html: page content and links
- style.css: layout, colors, responsive styling and animations
- script.js: mobile menu and scroll reveal interactions

BEFORE PUBLISHING, EDIT THESE PLACEHOLDERS IN index.html:
1. Replace every [Your Name] with your preferred display name.
2. Replace your.email@example.com with your real email address.
3. Replace https://github.com/yourusername with your GitHub profile URL.
4. Replace https://www.linkedin.com/in/yourusername/ with your LinkedIn profile URL.
5. Add links/screenshots to your real web projects when available.

IMPORTANT CONTENT NOTE:
The Spider Rescue Robot is described as a concept / in development. Keep that wording until the prototype and listed features are actually built and tested. Remove any skill you cannot confidently explain in an interview.

PREVIEW:
Open index.html in a browser. The site uses Google Fonts when online; it remains readable with fallback fonts offline.

PUBLISH:
You can deploy the folder using GitHub Pages, Netlify, or another static hosting service. Upload all three website files while keeping them in the same folder.
